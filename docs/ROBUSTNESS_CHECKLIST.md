# ROBUSTNESS_CHECKLIST

_Last updated: 2026-04-17_

## Minimum Checks Required Before Any Result Is Accepted
- [ ] Event-definition sensitivity documented.
- [ ] Window sensitivity documented.
- [ ] Overlap/clustering handling documented.
- [ ] Confound proximity checks (e.g., earnings/news) documented.
- [ ] Inference robustness documented.
- [ ] Exclusion/attrition impact documented.
- [ ] Interpretation limits explicitly restated in result note.

## Ownership
- Edge Case Agent prepares and validates checklist evidence.
- Synthesis & Interpretation Agent confirms reporting language matches evidence.
